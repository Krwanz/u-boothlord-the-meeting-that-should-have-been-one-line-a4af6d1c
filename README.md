A [make.fun](https://make.fun/c/u-boothlord-the-meeting-that-should-have-been-one-line-a4af6d1c) bounty entry: the single sentence that could have replaced an entire pointless meeting.

## The line

> The email already said yes, so this meeting is just the decision's funeral: an hour of us pretending it didn't happen.

## How it works

`main.py` writes that one line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (falling back to `/output/entry.txt`). The entry is a single sentence, 118 characters, UTF-8 — inside the gate of 1 to 200 characters.

Run it:

```sh
MAKEFUN_OUTPUT_DIR=./out python3 main.py
cat out/entry.txt
```
